# Проект bank card widget

## Описание:
Этот проект предоставляет функции для маскирования номеров карт и счетов, форматирования дат,
генерации номеров карт, а также позволяет смотреть информацию о транзакциях.
Он позволяет скрыть часть информации, чтобы защитить конфиденциальные данные.

## Установка:

1. Клонируйте репозиторий:
git clone https://github.com/Master2077/home-work.git

2. Установка зависимостей:
   poetry install

### Использование:

1. Запустите скрипт модуля masks
2. Введите номер карты и номер счета, когда будет предложено. Программа выведет замаскированные номера.
3. Запустите скрипт модуля generators
4. Введите интересущую вас валюту, когда будет предложено. Программа выведет информацию о транзакциях и сгенерирует номера карт

### Пример ввода:
Введите номер карты: 7000792289606361

Введите номер счета: 73654108430135874305

Введите название валюты USD/RUB: USD
