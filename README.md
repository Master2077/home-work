# Проект bank card widget

## Описание:
Этот проект предоставляет функции для маскирования номеров карт и счетов, а также для форматирования дат. Он позволяет скрыть часть информации, чтобы защитить конфиденциальные данные.

## Установка:

1. Клонируйте репозиторий:
git clone https://github.com/Master2077/home-work.git

2. Установка зависимостей:
   poetry install

### Использование:

1. Запустите скрипт
2. Введите номер карты и номер счета, когда будет предложено. Программа выведет замаскированные номера.

### Пример ввода:
Введите номер карты: 7000792289606361
Введите номер счета: 73654108430135874305

### Пример вывода:
Visa Platinum ********6361
Счет ****************5305
